# Подсчёт клеток в камере Горяева

Программа берёт снимок из файла или захватывает один кадр с USB-камеры микроскопа. Вы выделяете прямоугольный участок сетки, проверяете найденные клетки и получаете концентрацию исходной суспензии в клетках/мл.

## Установка

Понадобится Python 3 с поддержкой графических окон. Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте терминал в папке с `goryaev.py`. Установите зависимости:

```bash
python -m pip install opencv-python numpy matplotlib
```

В Windows вместо `python` можно использовать `py`, в Linux и macOS — `python3`.

## Запуск

Для снимка укажите путь к своему файлу:

```bash
python goryaev.py --image "sample.jpg" --cols 5 --rows 2 --diameter 14 --dilution 1
```

Для USB-микроскопа сначала наведите резкость, затем запустите:

```bash
python goryaev.py --camera 0 --cols 5 --rows 2 --diameter 14 --dilution 1
```

| Параметр | Как выбрать значение |
| --- | --- |
| `--cols`, `--rows` | Число **больших** квадратов по ширине и высоте выделяемого прямоугольника. По умолчанию 1 × 1. |
| `--diameter` | Примерный диаметр типичной клетки в пикселях исходного снимка, целое число от 3. Измерьте несколько клеток при текущем увеличении. Значение 14 в примерах замените своим. |
| `--dilution` | Коэффициент разведения. Введите 1 для исходной пробы или 10, если одну часть пробы смешали с девятью частями разбавителя. |
| `--bright` | Добавьте этот флаг для светлых клеток на тёмном фоне. По умолчанию программа ищет тёмные клетки. |
| `--camera` | Индекс камеры. Если открылась встроенная веб-камера, попробуйте 1. |

## Разметка и проверка

1. Выберите участок с нужным количеством больших квадратов. Оставьте в кадре небольшой запас вокруг него, чтобы были видны контуры пограничных клеток. Для подавления линий сетки лучше ориентировать их горизонтально и вертикально.
2. Щёлкните по четырём углам участка по порядку: **левый верхний → правый верхний → правый нижний → левый нижний**. Программа использует введённые `--rows` и `--cols` для расчёта объёма, поэтому сверьте их с разметкой.
3. Проверьте жёлтые крестики. Клетку на верхней или левой зелёной границе учитывают. Касание нижней или правой красной границы исключает клетку, в том числе в углу. Внутренние линии сетки на это правило не влияют.
4. **Левый щелчок** добавляет отметку вручную, **правый щелчок** рядом с отметкой удаляет её. При ручном добавлении соблюдайте правило границ самостоятельно. Если включали масштабирование или панорамирование, выключите этот режим перед исправлением отметок.
5. Нажмите **Enter**. В терминале появятся число учтённых клеток, просмотренный объём и концентрация.

## Как проверить расчёт

Для камеры с глубиной **0,1 мм** и стороной большого квадрата **0,2 мм** объём над одним большим квадратом равен 0,000004 мл. Сверьте размеры со своей камерой.

```text
Объём (мл) = cols × rows × 0,000004
Концентрация (клеток/мл) = число учтённых клеток × коэффициент разведения / объём
```

Например, 80 клеток в участке 5 × 2 больших квадрата дают 80 / 0,00004 = **2 000 000 клеток/мл** при коэффициенте разведения 1.

Детектор рассчитан на отдельные примерно округлые клетки. Для своего микроскопа сравните первый результат с ручным подсчётом. Особенно внимательно проверьте скопления клеток и пересечения с линиями сетки.
